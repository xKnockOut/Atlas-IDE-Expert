### Neu
- Eigenes Desktop-Layout im Formular-Designer (#2079, `designer.layout`, Vorgabe aus): Beim Wechsel in den Designer lädt Atlas das Layout aus `designer.layout.name` über das Desktop-Auswahlfeld der IDE, beim Wechsel zurück in den Code das vorherige oder das Standard-Layout der IDE (`designer.layout.returnTo`). Entprellt (300 ms), nicht während des Debuggens (`designer.layout.skipWhileDebugging`) und nicht, solange ein Projekt lädt; ein im Designer selbst gewähltes Layout bleibt. „Aktuelles Layout als Designer-Layout speichern …“ im Atlas-Menü öffnet den Dialog „Desktop speichern“ der IDE. Einstellungen unter Optionen › Atlas › Editor.
