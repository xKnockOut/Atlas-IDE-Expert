### Behoben
- Restliche Fehlalarme aus dem Lauf über fremde Delphi-Projekte (JCL, Indy, ZeosLib): `interface-not-implemented` vergleicht Parametertypen nicht mehr nur als Text, ein schlichter Alias (`TText = string`, `TW = UnicodeString`) gilt als sein Ziel, `type string` bleibt ein eigener Typ. `handle-leak` erkennt einen Merker mit zweitem Versuch nur bei Misserfolg (`Ok := OpenThreadToken(…); if not Ok then Ok := OpenProcessToken(…); if Ok then CloseHandle(…)`) und eine wiederholte, dazwischen unveränderte Bedingung (`if IsNT then` öffnen, später `if IsNT then` schließen). `inherited-wrong-method` schweigt, wenn die Klasse die gerufene Methode selbst überschreibt, ohne den Vorfahren aufzurufen (sortierte Menge: `Add` ruft `inherited Insert`, das eigene `Insert` ist gesperrt).
