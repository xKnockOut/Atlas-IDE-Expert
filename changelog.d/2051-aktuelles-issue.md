### Neu
- Das begonnene Issue für KI-Assistenten (#2051, `issues.shareWithAssistants`, Vorgabe an): Nach „Beginnen“ legt das Plugin `<gitdir>/atlas-current-issue.json` neben `atlas-commit-prefix` ab, mit Kennung, Titel, Tracker, Zustand, Meilenstein, Branch, Beschreibung, Checkliste mit Erledigt-Stand, Codeverweisen aus der Beschreibung und den letzten fünf Kommentaren. Das MCP-Werkzeug `get_current_issue` gibt es als Text oder JSON aus (`section`: summary, checklist, body, comments, all). Die Datei folgt dem Zwischenspeicher der Issue-Vorschau und enthält nie ein Token oder Anhangsadressen; mit der Einstellung aus oder ohne aktives Issue wird sie gelöscht. <!-- whatsnew title="Begonnenes Issue für KI-Assistenten" text="Nach „Beginnen“ liest ein KI-Assistent Issue, Checkliste und Codeverweise über get_current_issue, ohne Tracker-Zugang." titleEn="Started issue for AI assistants" textEn="After “Start” an AI assistant reads the issue, checklist and code references via get_current_issue, without tracker access." -->
