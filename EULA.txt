2. Bestandteile
   Atlas besteht aus einem Design-Time-Package für die RAD-Studio-IDE

3. Daten und Netzwerk

     Delphi-Installation nur lokal. Es lädt keine Quelltexte hoch und
     gibt keine Embarcadero-Quellen weiter.
   - Die Protokolle (Diagnose- und Serverprotokoll) werden lokal und
     anonymisiert gespeichert.
   - Die Update-Prüfung ruft eine Versionsdatei von GitHub ab
     (github.com/xKnockOut/Atlas-IDE-Expert). Dabei werden keine
     persönlichen Daten gesendet. Sie ist zunächst aus: Atlas fragt
     beim ersten Start und richtet sich nach Ihrer Antwort; in den
     Einstellungen (updates.check) lässt sie sich jederzeit ändern.
   - Fehlerberichte werden nie automatisch gesendet. Atlas öffnet dafür
     nur die Issue-Seite auf GitHub; was Sie dort eintragen, entscheiden Sie.

2. Components
   Atlas consists of a design-time package for the RAD Studio IDE

   process on your computer; it communicates with the IDE locally only.

3. Data and network
   - Atlas reads your source code and the RTL/VCL sources of your Delphi
     installation locally only. It uploads no source code and never
     redistributes Embarcadero sources.
   - Log files (diagnostic and server log) are stored locally and
     anonymised.
   - The update check downloads a version file from GitHub
     (github.com/xKnockOut/Atlas-IDE-Expert). No personal data is sent.
     It is off by default: Atlas asks on first start and follows your
     answer; you can change it at any time in the settings (updates.check).
   - Bug reports are never sent automatically. Atlas only opens the GitHub
     issue page; you decide what to submit there.
