Atlas 2.0.1 ordnet die Optionen nach Packages und zieht Versionsverwaltung und KI-Assistenten ganz in ihre Module.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.0.1). Nach dem Update zeigt die Karte „Neu in Atlas“ auf der Willkommensseite die wichtigsten Neuerungen.

## Optionen je Modul
- Unter Tools › Optionen › Atlas steht eine Übersicht mit dem Stand der Packages und einer Suche über alle Einstellungen; ein Klick auf einen Treffer springt hin (#1903).
- Unter „Module“ hat Base und jedes installierte Modul einen eigenen Knoten. Er erscheint und verschwindet mit dem Modul, ohne Neustart. Jeder Knoten speichert nur, was man dort geändert hat.
- Einstellungen, die zu einem anderen Modul gehören, stehen beim Eigentümer: Die Branch-Optionen des Issue-Trackers im Unterpunkt „Versionsverwaltung“ (nur mit Versionsverwaltung), die Schalter der Kacheln „Meine Issues“ und „Sprint“ auf der Willkommensseite.
- Der Schalter für die Code Insight von Atlas heißt jetzt so und steht unter Base.

## Module
- Versionsverwaltung als eigenes Modul (#1891, #1905): Einstellungsseite, Änderungsmarken mit Inline-Diff, Zeilenhistorie, „Branch anlegen …“ und „Arbeitskopien“.
- KI-Assistenten als eigenes Modul (#1888, #1906): Builds über `build_project` und Änderungen an offenen Dateien, mit eigener Optionsseite.

## Behoben
- Hover auf VCL-Klassen deutlich schneller; der Server lässt Hover, Vervollständigung und Diagnosen nicht mehr hinter langen Befehlen warten.
- Dunkles Thema: sechs Fenster zeigten weiße Zeilen bzw. schwarze Schrift.
- Reste abgestürzter IDEs werden beim Start aufgeräumt.
- Fehlalarme mehrerer Prüfregeln.

Atlas 2.0.1 organizes the options by package and moves version control and AI assistants fully into their modules.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.0.1, in German). After the update, the “What's new in Atlas” card on the welcome page shows the highlights.

## Options per module
- Under Tools › Options › Atlas there is an overview with the state of the packages and a search across all settings; clicking a result jumps there (#1903).
- Under “Modules”, Base and every installed module have their own node. It appears and disappears with the module, without a restart. Each node saves only what you changed there.
- Settings that belong to another module stay with their owner: the issue tracker's branch options in its “Version control” sub-node (only with version control), the switches of the “My issues” and “Sprint” tiles on the welcome page.
- The switch for Atlas Code Insight is now called that and sits under Base.

## Modules
- Version control as its own module (#1891, #1905): settings page, change marks with inline diff, line history, “Create branch …” and “Working copies”.
- AI assistants as their own module (#1888, #1906): builds via `build_project` and edits to open files, with their own options page.

## Fixed
- Hover on VCL classes is much faster; the server no longer makes hover, completion and diagnostics wait behind long commands.
- Dark theme: six windows showed white rows or black text.
- Leftovers of crashed IDEs are cleaned up at startup.
- False positives of several rules.
