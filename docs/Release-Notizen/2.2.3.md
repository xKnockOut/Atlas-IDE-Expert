Atlas 2.2.3 behebt einen Absturz der IDE nach dem Entladen von Atlas.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/v2.2.3/CHANGELOG.md) (Abschnitt 2.2.3).

## Behoben
- Absturz der IDE beim Beenden oder Neuinstallieren, Zugriffsverletzung in einem „unbekannten Modul“: Hielt die IDE den Code-Insight-Manager von Atlas nach dem Abmelden noch, gab sie ihn erst später frei, als der Code von Atlas.IDE.Base schon entladen war. Base bleibt in diesem Fall jetzt bis zum Ende der IDE im Speicher (#2372).

## Hinweis zum Aktualisieren aus dem Quelltext
- Vorher die alten Atlas-Packages unter Komponente › Packages installieren entfernen und Delphi neu starten, dann zuerst Atlas.IDE.Base und danach die Module installieren.

Atlas 2.2.3 fixes an IDE crash after Atlas was unloaded.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/v2.2.3/CHANGELOG.md) (section 2.2.3, in German).

## Fixed
- IDE crash on exit or reinstall, access violation in an "unknown module": if the IDE still held the Atlas Code Insight manager after it was unregistered, it released it later, when the code of Atlas.IDE.Base was already unloaded. In that case Base now stays in memory until the IDE ends (#2372).

## Updating from source
- First remove the old Atlas packages under Component › Install Packages and restart Delphi, then install Atlas.IDE.Base first and the modules after it.
