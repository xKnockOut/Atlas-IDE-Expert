*English version below.*

**Vorabversion.** Atlas 2.0.0-beta.1 ist die erste Beta von 2.0. Sie baut auf 1.2.0 auf und ändert vor allem den Aufbau des Plugins. Rückmeldungen bitte über „Problem melden …“ oder als Issue. Vorabversionen bietet die Update-Prüfung von 1.x nicht an; die Beta wird einmal von Hand installiert (siehe „Umstieg“).

Die vollständige Liste aller Änderungen steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.0.0-beta.1). Nach dem Update zeigt die Karte „Neu in Atlas“ auf der Willkommensseite die wichtigsten Neuerungen.

## Atlas in Modulen
- Das Plugin besteht jetzt aus dem Kern-Package `Atlas.IDE.Base` und elf Modulen: Debugger, Tests, Build-Werkzeuge, Build-Pipeline, Prüfregeln, Lesezeichen, Suche, Analyse, Designer, Issue-Tracker und Willkommensseite. Man installiert nur, was man braucht (#1454–#1456, ADR 0017).
- Jedes Modul hat einen Hauptschalter oben auf seiner Optionsseite und bringt seine Einstellungen selbst mit. Ein ausgeschaltetes Modul stoppt ohne Neustart; ein nicht installiertes fehlt im Optionsdialog, seine Werte bleiben erhalten. Neues Profil „Nur Code Insight“.

## Installieren und Aktualisieren
- Neu im Paket: `AtlasUpdate.exe` (#1519, ADR 0018). `AtlasUpdate install` richtet Atlas im Konsolendialog ein: IDE und Profil, Zielordner ohne Adminrechte, Module.
- Ab jetzt bietet „Jetzt aktualisieren“ ein neues Release an, lädt und prüft es im Hintergrund (SHA-256, bei signierten Releases auch die Signatur) und spielt es beim Schließen der IDE ein; bei einem Fehler nimmt es alles zurück. Einstellungen `updates.install`, `updates.channel` (auch Vorabversionen) und `updates.newModules`.
- Delphi 12: Das Paket enthält die BPLs für Delphi 13. Für Delphi 12 baut `AtlasUpdate` das Plugin aus dem Quelltext des Releases; dafür braucht es RAD Studio mit Kommandozeilen-Compiler (MSBuild).

## Prüfen
- Wann die offene Datei geprüft wird, ist einstellbar: live mit eigener Verzögerung, beim Speichern oder nur auf Anforderung (`problems.update`). „Datei jetzt prüfen“ hat ein eigenes Tastenkürzel, Vorgabe Strg+Umschalt+Alt+P (#1744).
- Neue Regel `dfm-reference-unit-missing`: Eine Formulardatei verweist auf eine Komponente eines anderen Formulars, dessen Unit nicht in den uses steht. Mit Korrektur „uses ergänzen“.
- `unused-uses` (#1135): Das Abblenden im Editor folgt jetzt der Regel (aus, Profil, `exclude`, `lsp-ignore`), neue Option `keep`. Einträge, die nur die Formulardatei braucht, gelten nicht mehr als ungenutzt.

## Sprache und Doku
- Atlas folgt der Sprache der IDE (#1458): Erklärungen der Prüfregeln, Beschreibungen der Einstellungen und die Karte „Neu in Atlas“ gibt es auch auf Englisch. Die Doku ist zweisprachig, mit englischen Seiten unter `docs/en`.

## Diagnose
- Protokolle, Fehlerbericht und Diagnosepaket sind vollständig anonym (#1478): Namen, Pfade und fremde Texte werden dort gekennzeichnet, wo die Zeile entsteht, und in jeder Ausgabe ersetzt. Klarnamen gibt es nur, wenn man sie ausdrücklich wählt (`diagnostics.log.names`).

## Behoben
- Projektgruppen brauchen deutlich weniger Speicher: übersetzte Packages (`.dcp`) einmal je Prozess, gemeinsamer Cache für Suchpfad-Units, keine doppelte Übernahme von Units. Die Zeit bis „bereit“ sinkt, weil der Server seine eigenen Cache-Sperren nicht mehr über die Datei prüft (#1479).
- Atlas-Suche unter Delphi 12: Strg+F schaltete die Suche nach drei Fehlversuchen ab.
- Die Liste „Atlas-Probleme“ im Meldungsfenster erschien bei bestehenden Installationen weiter, obwohl sie seit dem Fenster „Atlas-Prüfung“ Vorgabe aus ist.
- Fehlalarme in `handle-leak` und `owned-field-free-unclear`.

## Umstieg von 1.x
1. Delphi schließen. Das ZIP entpacken und `AtlasUpdate.exe install` ausführen. Es entfernt die alten Einträge (`Atlas.IDE.Expert…`, BetterDelphiLSP, Argus) aus den Known Packages und trägt Kern und Module ein.
2. Wer von Hand installiert: Den Eintrag `Atlas.IDE.Expert370.bpl` entfernen, dann zuerst `Atlas.IDE.Base370.bpl` und danach die gewünschten Module (`Atlas.IDE.<Modul>370.bpl`) hinzufügen. Eine Testfassung `Atlas.IDE.Contracts370.bpl` entfernen; dieses Package gibt es nicht mehr.
3. Einstellungen, Index, Snippets und Projektdateien bleiben erhalten. Das Protokoll heißt weiter `Atlas.IDE.Expert<Ver>.log`.

**Pre-release.** Atlas 2.0.0-beta.1 is the first beta of 2.0. It builds on 1.2.0 and mainly changes how the plugin is put together. Please send feedback via “Report a problem …” or as an issue. The update check of 1.x does not offer pre-releases, so install the beta once by hand (see “Upgrading”).

The full list of changes is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.0.0-beta.1, in German). After the update, the “What's new in Atlas” card on the welcome page shows the highlights.

## Atlas in modules
- The plugin now consists of the core package `Atlas.IDE.Base` and eleven modules: debugger, tests, build tools, build pipeline, rule checks, bookmarks, search, analysis, designer, issue tracker and welcome page. Install only what you need (#1454–#1456, ADR 0017).
- Each module has a main switch at the top of its options page and brings its own settings. A module that is switched off stops without a restart; a module that is not installed is missing from the options dialog, and its values are kept. New profile “Nur Code Insight” (Code Insight only).

## Installing and updating
- New in the package: `AtlasUpdate.exe` (#1519, ADR 0018). `AtlasUpdate install` sets up Atlas in a console dialog: IDE and profile, target folder without admin rights, modules.
- From now on, “Update now” offers a new release, downloads and verifies it in the background (SHA-256, and the signature for signed releases) and installs it when you close the IDE; on error it rolls everything back. Settings `updates.install`, `updates.channel` (including pre-releases) and `updates.newModules`.
- Delphi 12: the package contains the BPLs for Delphi 13. For Delphi 12, `AtlasUpdate` builds the plugin from the release source; this needs RAD Studio with the command-line compiler (MSBuild).

## Checks
- When the open file is checked is now configurable: live with its own delay, on save, or only on demand (`problems.update`). “Check file now” has its own shortcut, Ctrl+Shift+Alt+P by default (#1744).
- New rule `dfm-reference-unit-missing`: a form file refers to a component of another form whose unit is not in the uses clause. With the fix “add to uses”.
- `unused-uses` (#1135): dimming in the editor now follows the rule (off, profile, `exclude`, `lsp-ignore`), new option `keep`. Entries that only the form file needs no longer count as unused.

## Language and documentation
- Atlas follows the IDE language (#1458): rule explanations, setting descriptions and the “What's new in Atlas” card are also available in English. The documentation is bilingual, with English pages under `docs/en`.

## Diagnostics
- Logs, bug report and diagnostic package are fully anonymous (#1478): names, paths and foreign text are marked where the line is built and replaced in every output. Plain names only if you choose them explicitly (`diagnostics.log.names`).

## Fixed
- Project groups need much less memory: compiled packages (`.dcp`) once per process, a shared cache for search path units, no duplicate units. The time until “ready” drops because the server no longer probes its own cache locks through the file (#1479).
- Atlas search under Delphi 12: Ctrl+F switched the search off after three failed attempts.
- The “Atlas problems” list in the messages window still appeared in existing installations, although it has been off by default since the “Atlas check” window.
- False positives in `handle-leak` and `owned-field-free-unclear`.

## Upgrading from 1.x
1. Close Delphi. Unpack the ZIP and run `AtlasUpdate.exe install`. It removes the old entries (`Atlas.IDE.Expert…`, BetterDelphiLSP, Argus) from the Known Packages and registers the core and the modules.
2. Installing by hand: remove the entry `Atlas.IDE.Expert370.bpl`, then add `Atlas.IDE.Base370.bpl` first and the modules you want (`Atlas.IDE.<Module>370.bpl`) after it. Remove a test build of `Atlas.IDE.Contracts370.bpl`; this package no longer exists.
3. Settings, index, snippets and project files are kept. The log is still called `Atlas.IDE.Expert<Ver>.log`.
