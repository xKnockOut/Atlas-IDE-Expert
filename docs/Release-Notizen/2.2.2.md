*English version below.*

Atlas 2.2.2 verhindert, dass Module aus einem anderen Bau neben Atlas.IDE.Base laufen.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.2.2).

## Behoben
- Module aus einem anderen Bau als Atlas.IDE.Base laden nicht mehr bzw. melden sich nicht an: Der Handschlag zwischen Modul und Base prüft jetzt außer der Vertragsversion auch die Produktversion. Vorher konnte z. B. ein aus dem Quelltext gebautes 2.2.1-Modul neben einem installierten 2.2.0-Base laufen, gegen eine fremde Binärschnittstelle (#2372).

## Hinweis zum Aktualisieren aus dem Quelltext
- Vorher die alten Atlas-Packages unter Komponente › Packages installieren entfernen und Delphi neu starten, dann zuerst Atlas.IDE.Base und danach die Module installieren.
- Ein Mischstand aus zwei Versionen zeigt beim Start je Modul „Einsprungpunkt nicht gefunden“ und startet Atlas beim nächsten Mal einmal im abgesicherten Modus.

---

Atlas 2.2.2 prevents modules from a different build from running next to Atlas.IDE.Base.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.2.2, in German).

## Fixed
- Modules from a different build than Atlas.IDE.Base no longer load or register: the handshake between module and Base now checks the product version as well as the contract version. Before, a 2.2.1 module built from source could, for example, run next to an installed 2.2.0 Base, against a foreign binary interface (#2372).

## Updating from source
- First remove the old Atlas packages under Component › Install Packages and restart Delphi, then install Atlas.IDE.Base first and the modules after it.
- A mix of two versions shows "entry point not found" for each module at startup and starts Atlas once in safe mode the next time.
