*English version below.*

Atlas 2.2.0-rc.2 ist die zweite Vorabversion von 2.2.0. Sie behebt Fehler aus rc.1 und bringt weitere Fenster ins Thema der IDE. Was 2.2.0 insgesamt bringt (Debuggen, Testen, Lecks), steht in den Notizen zu 2.2.0-rc.1.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.2.0-rc.2).

## Behoben
- Debugger: F9 setzt ein angehaltenes Programm wieder fort und Strg+F2 beendet es wieder, auch mit eingeschalteten Startverbünden.
- Tests mit `[TestCase]` werden im Fenster „Atlas-Tests“, an der Testmarke und in der Statusleiste wieder grün bzw. rot.
- Update-Prüfung: Nach einem Kanalwechsel fragt Atlas den neuen Kanal sofort ab (#1519).
- Profiler: Endet der Server während eines Profil-Laufs, bleibt kein Thread des gemessenen Programms angehalten zurück (#2057).
- Mutationslauf: Ein hängendes Testprogramm hält die IDE nicht mehr auf, Units ohne Formular lassen sich wieder prüfen.
- Units suchen zeigt Units nicht mehr doppelt, wenn ein zweiter Checkout desselben Projekts auf der Platte liegt.
- `xmldoc-mismatch` meldet Typargumente wie `TList<Integer>` im Doku-Text nicht mehr als Fehler; `inline-not-expanded` ohne Fehlalarme bei System und generischen Typen (#2309).

## Oberfläche
- Befehlspalette, Designer-Dialoge, Status, Benachrichtigungen, Schnellschalter, Atlas-Einrichtung, „Mitglieder herauslösen“, „Units suchen“ und weitere Fenster folgen dem IDE-Thema, auch beim Wechsel im offenen Fenster.
- „Regel erklären“ und „Gelernte Vorschläge“ passen sich der Fenstergröße an; umbrechende Hinweise in rund 50 Fenstern wachsen mit der Breite.

## Neu
- Wortgleiche Rümpfe über Units hinweg: `AtlasServer --check --check-duplicates` und Regel `duplicate-routine-body` (Profil strict).

---

Atlas 2.2.0-rc.2 is the second pre-release of 2.2.0. It fixes bugs from rc.1 and brings more windows in line with the IDE theme. For everything 2.2.0 brings (debugging, testing, leaks), see the notes for 2.2.0-rc.1.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.2.0-rc.2, German).

## Fixed
- Debugger: F9 resumes a paused program and Ctrl+F2 ends it again, also with launch groups enabled.
- Tests with `[TestCase]` turn green or red again in the "Atlas Tests" window, at the test mark and in the status bar.
- Update check: after switching the channel, Atlas queries the new channel right away (#1519).
- Profiler: if the server ends during a profiling run, no thread of the measured program stays suspended (#2057).
- Mutation run: a hanging test program no longer blocks the IDE, units without a form can be checked again.
- Unit search no longer lists units twice when a second checkout of the same project is on disk.
- `xmldoc-mismatch` no longer reports type arguments such as `TList<Integer>` in doc text; `inline-not-expanded` without false alarms for System and generic types (#2309).

## Interface
- Command palette, designer dialogs, status, notifications, quick toggles, Atlas setup, "Extract members", "Search units" and further windows follow the IDE theme, including a switch while open.
- "Explain rule" and "Learned suggestions" adapt to the window size; wrapping hints in about 50 windows grow with the width.

## New
- Identical bodies across units: `AtlasServer --check --check-duplicates` and rule `duplicate-routine-body` (profile strict).
