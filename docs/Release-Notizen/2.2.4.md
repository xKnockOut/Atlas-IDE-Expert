*English version below.*

Atlas 2.2.4 behebt Abstürze beim Entladen von Packages und beim Bauen, Hänger der IDE im Tooltip und bei der Referenzsuche sowie mehrere kleinere Fehler. Neu: Jeder Atlas-Befehl lässt sich mit einer eigenen Taste belegen.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/v2.2.4/CHANGELOG.md) (Abschnitt 2.2.4).

## Neu
- Tastenkürzel für jeden Atlas-Befehl (#2938): Im Fenster *Atlas – Tastenkürzel* zeigt „Auch Befehle ohne Taste“ alle Befehle der Befehlspalette, „Zuweisen …“ nimmt die nächste Taste auf. „Methode suchen …“ liegt ab Werk auf Strg+D, das nächste Vorkommen der Mehrfachmarken deshalb auf Strg+Alt+D (eine selbst gewählte Belegung bleibt).

## Behoben
- Fenster „Atlas – Tastenkürzel“ und weitere Listen im dunklen IDE-Thema: keine weißen, leer wirkenden Zeilen mehr; Listen flackern beim Überfahren nicht mehr.
- Abstürze beim Installieren, Entfernen oder Entladen von Packages und beim Beenden der IDE: „Fehler in Einstellungen“ (Tastenkürzel, etwa neben TestInsight), Willkommensseite, Statusfeld und Benachrichtigungen hielten Code eines abgemeldeten Atlas-Moduls.
- Bauen: Die Designer-Leiste stürzt bei „Alle bauen“ nicht mehr ab; die Syntaxprüfung nach dem Speichern startet den Compiler nicht mehr mitten im Build einer Projektgruppe, und der Einfrier-Wächter hält den Hauptthread während des Übersetzens nicht mehr an (interne Compilerfehler F2084).
- Hover-Tooltip und Referenzsuche halten die IDE nicht mehr an; kein „ELspTimeoutError“ mehr beim Klick auf einen Typ im Tooltip.
- `/sortuses` kommt auch in sehr großen Units rechtzeitig an.
- Klick auf Gutter-Symbole, „Wer gibt das frei?“-Marken, Inlay-Hinweise und den Kopf des Sticky Scroll markiert keinen Text bzw. keine Zeile mehr.
- Fenster „Atlas: Ereignisprotokoll“ zählt nicht mehr endlos hoch; Fenster „Haltepunkte“ bricht bei schmaler Breite um.
- Sprachserver meldet beim Beenden der IDE keinen Schreibfehler auf die geschlossene Pipe mehr.
- YouTrack-Meldungen zu meinen Issues funktionieren mit deutscher Systemsprache.
- Prüfregel `delimited-text-without-strict` ohne Fehlalarm bei `with` und Typumwandlung.

## Hinweis zum Aktualisieren aus dem Quelltext
- Vorher die alten Atlas-Packages unter Komponente › Packages installieren entfernen und Delphi neu starten, dann zuerst Atlas.IDE.Base und danach die Module installieren.

Atlas 2.2.4 fixes crashes when packages are unloaded and while building, IDE freezes in the tooltip and in the reference search, and several smaller bugs. New: every Atlas command can get its own shortcut.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/v2.2.4/CHANGELOG.md) (section 2.2.4, in German).

## New
- Shortcuts for every Atlas command (#2938): in the *Atlas – Shortcuts* window, "Also commands without a key" lists all commands of the command palette, "Assign …" records the next key. "Find method …" is on Ctrl+D by default, so the next occurrence of multiple carets moves to Ctrl+Alt+D (a key you chose yourself stays).

## Fixed
- The *Atlas – Shortcuts* window and other lists in the dark IDE theme: no more white rows that look empty; lists no longer flicker on mouse-over.
- Crashes when installing, removing or unloading packages and when closing the IDE: "Error in settings" (shortcuts, e.g. next to TestInsight), welcome page, status field and notifications held code of an unregistered Atlas module.
- Building: the designer bar no longer crashes on "Build all"; the syntax check after saving no longer starts the compiler in the middle of a project group build, and the freeze watchdog no longer suspends the main thread while compiling (internal compiler errors F2084).
- The hover tooltip and the reference search no longer block the IDE; no more "ELspTimeoutError" when clicking a type in the tooltip.
- `/sortuses` arrives in time even in very large units.
- Clicking gutter symbols, "Who frees this?" marks, inlay hints or the sticky scroll header no longer selects text or the line.
- The "Atlas: Event Log" window no longer counts up endlessly; the "Breakpoints" window wraps when narrow.
- The language server no longer logs a write error on the closed pipe when the IDE exits.
- YouTrack notifications about my issues work with a German system language.
- Rule `delimited-text-without-strict` no longer reports false positives with `with` and type casts.

## Updating from source
- First remove the old Atlas packages under Component › Install Packages and restart Delphi, then install Atlas.IDE.Base first and the modules after it.
