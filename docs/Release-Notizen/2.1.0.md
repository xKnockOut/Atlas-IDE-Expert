*English version below.*

Atlas 2.1.0 bringt die ganze Reihe der Werkzeuge für den Formular-Designer, eine deutlich reichere Brotkrumenleiste, lernende Vorschläge aus dem eigenen Code und einen Issue-Tracker, der dem Workflow von YouTrack folgt. Neu dazu kommt AtlasMonitor, das alle laufenden Atlas-Server zeigt und ohne IDE prüft.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.1.0). Nach dem Update zeigt die Karte „Neu in Atlas“ auf der Willkommensseite die wichtigsten Neuerungen.

## Formular-Designer
- Knopf „Anordnen“ in der Designer-Leiste: Breite nach Text, Knopfleiste, Label-Feld-Paare als Formularraster, in Reihe duplizieren, Platz einfügen und entfernen, an Inhalt anpassen, Ebenen, Einpacken in Container, Schriften und Farben vereinheitlichen, Anchors vorschlagen, Format-Pinsel, Gruppen ohne Container (#726–#749).
- Abstände beim Verschieben messen und per Griff festlegen, gemeinsame Größengriffe, Schnellleiste über der Mehrfachauswahl, Lupe, räumliche Navigation mit Alt+Pfeil, Beschriftung direkt bearbeiten (F2).
- Tab-Reihenfolge einblenden, Formulargröße und Skalierung ausprobieren, sprechende Komponentennamen, Fenster „Atlas-Struktur“ und „Ereignis-Karte“, Datenbindung als Leiste, Auswahl in einen Frame auslagern, Verwendungen im Code, Komponenten und Eigenschaften suchen (#511–#612).
- Rückgängig im Designer (#1887) ist experimentell und muss eingeschaltet werden.

## Editor und Navigation
- Brotkrumenleiste: Sichtbarkeit, Unterblock, Deklarationsblock, Region, Bedingungszweig, try/except und case-Zweig, Überladungen, erfülltes Interface, Kennzahlen-Karte und Rechtsklick-Menü (#1759–#1787).
- Gelernte Vorschläge (#1890): Atlas lernt wiederkehrende Folgen aus dem eigenen Code und schlägt die nächste Zeile als Schattentext vor, ohne KI.
- Hover zeigt Parameter und Rückgabe immer untereinander (#1919), über uses-Einträgen die Typen der Unit (#1921), unter Compilermeldungen die Ursache (#54) und unter Befunden ein Beispiel (#145).
- Einstellungen durchsuchen (#1884), F1-Hilfe zu Befunden, Einstellungen und Fenstern (#1886), Maustasten Zurück und Vor (#1889), Atlas im Kontextmenü der Projektverwaltung (#1817), Fehler der IDE neben den Atlas-Befunden (#1819), Befunde folgen ihrer Zeile sofort (#1818).
- Methode extrahieren ersetzt auf Wunsch gleiche Stellen in der Unit (#2054).

## Issue-Tracker
- Tracker-Projekt in „Meine Issues“ frei wählen oder alle gemeinsam zeigen, Arbeitskopien je Projekt (#1926–#1929), Arbeitsstand je Issue in „Weiterarbeiten“ (#2052).
- YouTrack-Ablauf: Beginnen und Beenden lösen erlaubte Übergänge aus, Beenden bucht Zeit und Pflichtfelder in der richtigen Reihenfolge, Zustand und Übergänge im Statusfeld, Aufnahme in den laufenden Sprint, wieder geöffnete Issues, „Prüfen …“ für Issues im Prüfzustand (#2122–#2128).
- Board mit Swimlanes und Ablauf-Karte der letzten Zustandswechsel.

## AtlasMonitor
- Neues Programm im Release-Paket (#1900, #1901): Fenster und Symbol im Infobereich für alle laufenden Atlas-Server, Server beenden, Protokolle öffnen, Cache leeren; der Reiter „Prüfen“ prüft Ordner, Projekte und Projektgruppen ganz ohne IDE und exportiert HTML oder SARIF.

## Prüfregeln
- Neue Regeln, unter anderem `uses-only-in-implementation`, `security-hardcoded-credential`, `control-fixed-bounds`, `dunitx-areequal-length`, `ignored-result`, `method-order` und Regeln für die Umstellung auf Win64 und Unicode; weitere Compilerfallen, die erst Delphi ablehnt.
- `unused-uses` zählt Units über die echte Namensauflösung (#1925); viele Fehlalarme aus der Prüfung über 19 fremde Projekte behoben.

## Behoben und schneller
- Der Server arbeitet mit eigenen Threads; kurze Anfragen warten nicht mehr hinter langen. „Units suchen“, die Editorleiste und die Brotkrumen halten die IDE nicht mehr an.
- Rechtsklick in der Projektverwaltung ließ Delphi einfrieren; Leisten am Designer lagen übereinander; die Suchleiste sprang zu Treffern eines anderen Texts.
- Alle Atlas-Dialoge folgen jetzt dem hellen und dunklen Thema der IDE (#2061–#2065).

Atlas 2.1.0 brings the full set of tools for the form designer, a much richer breadcrumb bar, learned suggestions from your own code and an issue tracker that follows the YouTrack workflow. New is AtlasMonitor, which shows all running Atlas servers and checks without the IDE.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.1.0, in German). After the update, the “What's new in Atlas” card on the welcome page shows the highlights.

## Form designer
- “Arrange” button in the designer bar: width to text, button bar, label/field pairs as form grid, duplicate in a row, insert and remove space, fit to content, layers, wrap in container, unify fonts and colors, suggest anchors, format painter, groups without container (#726–#749).
- Measure spacing while moving and set it by handle, shared size handles, quick bar over a multi-selection, magnifier, spatial navigation with Alt+arrow, edit captions in place (F2).
- Show tab order, try form sizes and scaling, meaningful component names, “Atlas Structure” and “Event map” windows, data binding bar, extract the selection to a frame, usages in code, find components and properties (#511–#612).
- Undo in the designer (#1887) is experimental and must be switched on.

## Editor and navigation
- Breadcrumb bar: visibility, sub-block, declaration block, region, conditional branch, try/except and case branch, overloads, implemented interface, metrics card and right-click menu (#1759–#1787).
- Learned suggestions (#1890): Atlas learns recurring sequences from your own code and suggests the next line as ghost text, without AI.
- Hover always lists parameters and result one below the other (#1919), shows the types of a unit over uses entries (#1921), the cause under compiler messages (#54) and an example under findings (#145).
- Search settings (#1884), F1 help for findings, settings and windows (#1886), mouse back and forward buttons (#1889), Atlas in the project manager context menu (#1817), IDE errors next to the Atlas findings (#1819), findings follow their line immediately (#1818).
- Extract method optionally replaces identical code in the unit (#2054).

## Issue tracker
- Choose the tracker project in “My issues” or show all together, working copies per project (#1926–#1929), work state per issue in “Continue” (#2052).
- YouTrack workflow: start and finish fire allowed transitions, finish books time and required fields in the right order, state and transitions in the status bar, adding to the running sprint, reopened issues, “Review …” for issues in a review state (#2122–#2128).
- Board with swimlanes and an activity map of recent state changes.

## AtlasMonitor
- New program in the release package (#1900, #1901): window and notification area icon for all running Atlas servers, stop servers, open logs, clear the cache; the “Check” tab checks folders, projects and project groups without the IDE and exports HTML or SARIF.

## Check rules
- New rules, among them `uses-only-in-implementation`, `security-hardcoded-credential`, `control-fixed-bounds`, `dunitx-areequal-length`, `ignored-result`, `method-order` and rules for moving to Win64 and Unicode; more compiler traps that only Delphi rejects.
- `unused-uses` counts units by real name resolution (#1925); many false positives from the check over 19 third-party projects fixed.

## Fixed and faster
- The server uses its own worker threads; short requests no longer wait behind long ones. “Unit search”, the editor bar and the breadcrumbs no longer stall the IDE.
- Right-click in the project manager froze Delphi; bars on the designer overlapped; the search bar jumped to matches of another text.
- All Atlas dialogs now follow the light and dark theme of the IDE (#2061–#2065).
