*English version below.*

Atlas 2.2.5 behebt einen Absturz der Designer-Leiste und der Atlas-Struktur, Hänger beim Bauen und mehrere sichtbare Fehler in Tooltips, Hover, Debug-Hover, „Methode suchen“ und im Fenster „Atlas-Prüfung“. Neue Funktionen enthält diese Version nicht.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/v2.2.5/CHANGELOG.md) (Abschnitt 2.2.5).

## Behoben
- Bauen einer Projektgruppe („Alle erzeugen“): keine Zugriffsverletzung mehr in der Designer-Leiste, wenn Rückgängig im Designer an ist. Aufträge nach dem Build warten, bis kein Fortschrittsdialog und kein anderer modaler Dialog mehr offen ist.
- Atlas-Struktur: kein Absturz der IDE mehr beim Aus- oder Einblenden nichtvisueller Komponenten bei einem Datenmodul oder während eines Formularwechsels.
- Hänger beim Bauen und beim Anmelden der Module (bis 1,5 s): Die Abfrage der Modulschalter und gesperrte Datendateien kosten keine Zeit mehr.
- YouTrack-Meldungen zu meinen Issues: kein HTTP 400 („Can't parse search query“) mehr bei deutscher Systemsprache.
- Tooltips ohne eigene Farben (etwa „Wer gibt das frei?“) erscheinen im dunklen IDE-Thema dunkel.
- Mitlaufender Kopf im Editor: Atlas-Zeichnungen (Werte beim Debuggen, Inlay-Hints, Code Lens, Markierungen …) liegen nicht mehr über den Kopfzeilen.
- Hover über einen Namen aus einer Liste (`A, B: Integer`) zeigt nur diesen Namen.
- Debug-Hover: „Set to False/True“ und „Change …“ wirken auch bei neu deklarierten Eigenschaften wie `TButton.Enabled`; der Datenfluss folgt der geerbten Deklaration.
- „Methode suchen“, Gliederung und projektweite Symbolsuche finden lokale (verschachtelte) Routinen.
- Fenster „Atlas-Prüfung“: Fehler der IDE stehen als „IDE-Fehler“ statt als Gruppe ohne Namen.
- Hängerprotokoll: „Atlas im Aufrufstapel“ zählt nur noch Code von Atlas; Rahmen der Module tragen Unit und Routine.

## Geändert
- atlas.log nennt vor und nach jedem Gruppenlauf den belegten Adressraum der IDE und den größten freien Block. Das hilft bei internen Compilerfehlern (F2084) in der 32-Bit-IDE.

## Hinweis zum Aktualisieren aus dem Quelltext
- Vorher die alten Atlas-Packages unter Komponente › Packages installieren entfernen und Delphi neu starten, dann zuerst Atlas.IDE.Base und danach die Module installieren. Die Vertragsversion ist 35; Module aus 2.2.4 melden sich mit Base 2.2.5 nicht an.

Atlas 2.2.5 fixes a crash of the designer bar and of the Atlas Structure window, freezes while building, and several visible bugs in tooltips, hover, debug hover, "Find method" and the "Atlas Findings" window. This version has no new features.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/v2.2.5/CHANGELOG.md) (section 2.2.5, in German).

## Fixed
- Building a project group ("Build all"): no more access violation in the designer bar when designer undo is on. Jobs after the build wait until no progress dialog and no other modal dialog is open.
- Atlas Structure: the IDE no longer crashes when hiding or showing non-visual components of a data module or while switching forms.
- Freezes while building and while modules register (up to 1.5 s): querying the module switches and locked data files no longer cost time.
- YouTrack notifications about my issues: no more HTTP 400 ("Can't parse search query") with a German system language.
- Tooltips without their own colors (such as "Who frees this?") are dark in the dark IDE theme.
- Sticky header in the editor: Atlas drawings (debug values, inlay hints, code lens, highlights …) no longer cover the header lines.
- Hovering a name from a list (`A, B: Integer`) shows only that name.
- Debug hover: "Set to False/True" and "Change …" also work for redeclared properties such as `TButton.Enabled`; data flow follows the inherited declaration.
- "Find method", the outline and the project-wide symbol search find local (nested) routines.
- "Atlas Findings" window: IDE errors are listed as "IDE error" instead of a group without a name.
- Freeze log: "Atlas on the call stack" counts only Atlas code; module frames show unit and routine.

## Changed
- atlas.log shows the IDE's used address space and the largest free block before and after each group build. This helps with internal compiler errors (F2084) in the 32-bit IDE.

## Updating from source
- First remove the old Atlas packages under Component › Install Packages and restart Delphi, then install Atlas.IDE.Base first and the modules after it. The contract version is 35; modules from 2.2.4 do not register with Base 2.2.5.
