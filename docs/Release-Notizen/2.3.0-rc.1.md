*English version below.*

Atlas 2.3.0-rc.1 ist die Vorabversion von 2.3.0, dem Release für das Fundament und die KI-Assistenten. KI-Assistenten debuggen jetzt in der laufenden IDE, sehen, wo der Entwickler gerade ist, und bekommen 17 neue MCP-Werkzeuge (jetzt 55). Dazu kommen zehn neue Prüfregeln, weitere Debug-Funktionen und viele Korrekturen und Aufräumarbeiten im Inneren des Plugins.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.3.0-rc.1). Nach dem Update zeigt die Karte „Neu in Atlas“ auf der Willkommensseite die wichtigsten Neuerungen.

## KI-Assistenten
- Debuggen in der laufenden IDE über MCP: Projekt oder einzelnen DUnitX-Test starten, Haltepunkte, Schritte, Aufrufstapel, lokale Werte und Ausdrücke (`debug_start`, `debug_step`, `debug_state`, `debug_evaluate` …); standardmäßig aus, eine Leiste zeigt, wer debuggt, mit „Pause für KI“ und „Übernehmen“ (#1874).
- Anzeige „KI-Assistent aktiv“ im Statusfeld mit Pause für KI (#1906); geschützte Dateien, die Assistenten nicht ändern dürfen (#2608); Anweisungsdatei für Assistenten aus `atlas.json` (`--write-instructions`, #2615).
- Neue MCP-Werkzeuge: `get_ide_context` (#2050), `get_current_issue` (#2051), `get_last_tests` (#2409), `explain_compiler_message` (#2621), `find_implementations` (#2635), `batch` (#2638), `search_atlas_docs` (#2376), `get_symbol_history` (#2641), `refactor` (#2150).
- Schreibende Werkzeuge melden die neuen und behobenen Befunde nach der Änderung (#2603); Aufrufstatistik je Werkzeug und Sitzung (#2611).
- KI-Anbieter im Plugin: KI-Schattentext nach Enter, geprüft vom Server, standardmäßig aus (#1922); OpenAI-kompatible Server für lokale Modelle und Firmen-Gateways (#2056); Issue mit KI zusammenfassen (#2462).
- Befunde als Auftrag für einen KI-Assistenten kopieren (#2570).

## Debuggen
- Haltepunkt nur, wenn eine bestimmte Methode im Aufrufstapel steht (#2548); bei Exceptions nach Meldungstext anhalten oder fortsetzen (#2549); Exception-Regeln nach Klasse und Ort, auch fürs Team (#838).
- Anhalten bei SQL oder HTTP (#870), Laufzeit zwischen Haltepunkten (#579), Objekte markieren (#839), überwachte Ausdrücke je Klasse oder Unit (#2550).
- Bekannte Fehler aus dem Issue-Tracker beim Exception-Halt (#2460), Debug-Zustand als Notiz festhalten (#582), vom Debugger geöffnete Dateien wieder schließen (#842).
- Experimentell: Rückgabewerte nach dem Verlassen einer Funktion (#844), Ausführungspfeil ziehen (#871).

## Prüfregeln und Code
- Neue Regeln: `thread-execute-without-except` (#2632), `multiple-create-in-try` (#2630), `sleep-polling-loop` (#2626), `virtual-call-in-constructor` (#2623), dazu sechs Delphi-Fallen, die Free Pascal übersetzt, Delphi aber nicht (#2095, #1899).
- `/sortuses` gliedert die uses nach Herkunft (#2794); einheitliche Leerzeilen um Methodenrümpfe (#1839).
- Schneller: die Rumpfregeln in großen Units (#1477); `--check` arbeitet mit der Projektgruppe über dem Projekt (#1895).

## Behoben
- Umbenennen eines Parameters ändert Deklaration und Rumpf zusammen (#2425), gleichnamige Typen bleiben unberührt (#1896).
- Hohe DPI: Spalten, Panels und über `SetBounds` gesetzte Maße skalieren in allen Atlas-Fenstern (#2060, #2675); Knöpfe der Designer-Leiste behalten ihren Zustand (#2546).
- Scheitert ein Befehl, steht der erste Fehler mit Befehl und Fehlerklasse gleich in der Meldungsansicht.

## Im Inneren
- Plugin nach dem Rollenkonzept ausgerichtet: Adapter und Provider in eigenen Units, Abläufe ohne IDE in Core und dort getestet (#1443).
- Kopien zusammengelegt (JSON-Lesehelfer, Token-Helfer, Fenster- und Editor-Kleinteile; #1969, #1979, #1973); überfällige Hintergrund-Threads laufen nicht mehr in entladenem Modul-Code weiter (#1961).

Atlas 2.3.0-rc.1 is the pre-release of 2.3.0, the release for the foundation and AI assistants. AI assistants now debug in the running IDE, see where the developer currently is and get 17 new MCP tools (now 55). On top come ten new check rules, more debugging features and many fixes and clean-ups inside the plugin.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.3.0-rc.1, German). After the update, the "What's new in Atlas" card on the welcome page shows the main changes.

## AI assistants
- Debugging in the running IDE over MCP: start a project or a single DUnitX test, breakpoints, steps, call stack, locals and expressions (`debug_start`, `debug_step`, `debug_state`, `debug_evaluate` …); off by default, a bar shows who is debugging, with "Pause for AI" and "Take over" (#1874).
- "AI assistant active" display in the status field with pause for AI (#1906); protected files that assistants must not change (#2608); instruction file for assistants from `atlas.json` (`--write-instructions`, #2615).
- New MCP tools: `get_ide_context` (#2050), `get_current_issue` (#2051), `get_last_tests` (#2409), `explain_compiler_message` (#2621), `find_implementations` (#2635), `batch` (#2638), `search_atlas_docs` (#2376), `get_symbol_history` (#2641), `refactor` (#2150).
- Writing tools report the new and fixed findings after the change (#2603); call statistics per tool and session (#2611).
- AI providers in the plugin: AI ghost text after Enter, checked by the server, off by default (#1922); OpenAI-compatible servers for local models and company gateways (#2056); summarize an issue with AI (#2462).
- Copy findings as a task for an AI assistant (#2570).

## Debugging
- Breakpoint only when a given method is on the call stack (#2548); stop or continue on exceptions by message text (#2549); exception rules by class and location, also for the team (#838).
- Break on SQL or HTTP (#870), run time between breakpoints (#579), mark objects (#839), watches per class or unit (#2550).
- Known errors from the issue tracker at an exception stop (#2460), capture the debug state as a note (#582), close files the debugger opened (#842).
- Experimental: return values after leaving a function (#844), drag the execution point (#871).

## Check rules and code
- New rules: `thread-execute-without-except` (#2632), `multiple-create-in-try` (#2630), `sleep-polling-loop` (#2626), `virtual-call-in-constructor` (#2623), plus six Delphi pitfalls that Free Pascal compiles but Delphi does not (#2095, #1899).
- `/sortuses` groups the uses by origin (#2794); consistent blank lines around method bodies (#1839).
- Faster: the body rules in large units (#1477); `--check` works with the project group above the project (#1895).

## Fixed
- Renaming a parameter changes declaration and body together (#2425), types of the same name stay untouched (#1896).
- High DPI: columns, panels and sizes set through `SetBounds` scale in all Atlas windows (#2060, #2675); designer bar buttons keep their state (#2546).
- When a command fails, the first error with command and error class shows up in the messages view right away.

## Inside
- Plugin aligned with the role concept: adapters and providers in their own units, flows without the IDE in Core and tested there (#1443).
- Copies merged (JSON readers, token helpers, small window and editor parts; #1969, #1979, #1973); overdue background threads no longer keep running in unloaded module code (#1961).
