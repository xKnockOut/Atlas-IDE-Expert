*English version below.*

Atlas 2.2.0-rc.3 ist die dritte Vorabversion von 2.2.0. Sie behebt Fehler aus rc.2, macht Atlas-Fenster im Desktop-Layout verlässlich und bringt drei kleine neue Funktionen. Was 2.2.0 insgesamt bringt (Debuggen, Testen, Lecks), steht in den Notizen zu 2.2.0-rc.1.

Die vollständige Liste steht im [Changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (Abschnitt 2.2.0-rc.3).

## Neu
- uses-Einträge im interface, die nur die implementation braucht, erscheinen im Editor in Hinweisfarbe (#2465, `editor.highlightMovableUses`).
- Das Fenster „Atlas-Tests“ öffnet sich bei Fehlschlägen von selbst (#2467, `tests.window.openOnFailure`).
- Alle andockbaren Atlas-Fenster lassen sich unter *Ansicht › Atlas* öffnen.

## Behoben
- Debug-Bau: Atlas.IDE.Base meldete gleich nach dem Laden `ERangeError` (Maustasten Zurück/Vor); weitere Bereichsfehler bei beschädigten Zeitstempeln behoben.
- Atlas-Fenster im Desktop-Layout tragen feste Namen und sind alle bei der IDE angemeldet. Sie behalten ihren Platz nach dem Neustart. Ein vorhandenes Layout einmal neu anordnen und speichern.
- Gliederung, Schnellschalter, Statusfeld, Benachrichtigungen und andere Atlas-Popups flackern nicht mehr.
- Delphi 12: Das eigene Help-Insight-Fenster der IDE erscheint nicht mehr neben dem Atlas-Tooltip.
- Blocklinien beginnen bei umbrochenen `if`-, `while`-, `for`- und `with`-Köpfen an der richtigen Zeile.
- Fenster und Menüs an der Schreibmarke öffnen sich bei 150 und 200 Prozent Skalierung direkt unter der Zeile.
- Mutationslauf: Abbrüche behalten das bis dahin Geprüfte, Projekte mit `.rc`, Umlauten oder offenem Kommentar in der .dpr hängen oder scheitern nicht mehr.
- Designer: Rückgängig von „Label erzeugen“, „Duplizieren“ und „Einpacken“ löscht nur noch, was das Werkzeug selbst angelegt hat.
- `format-without-settings` ohne Fehlalarme bei eigenen gleichnamigen Routinen; `duplicate-routine-body` liest jede Datei nur noch einmal.

## Qualität
- Die Testsuite läuft unter Delphi ohne Leck und ohne vorgezogene Aufwärmtests. Der Speicherrest beim Beenden ist ein Kriterium jedes Testlaufs.

---

Atlas 2.2.0-rc.3 is the third pre-release of 2.2.0. It fixes bugs from rc.2, makes Atlas windows in the desktop layout reliable and adds three small features. For everything 2.2.0 brings (debugging, testing, leaks), see the notes for 2.2.0-rc.1.

The full list is in the [changelog](https://github.com/xKnockOut/Atlas-IDE-Expert/blob/main/CHANGELOG.md) (section 2.2.0-rc.3, German).

## New
- uses entries in the interface that only the implementation needs are shown in hint colour in the editor (#2465, `editor.highlightMovableUses`).
- The "Atlas Tests" window opens by itself on failures (#2467, `tests.window.openOnFailure`).
- All dockable Atlas windows can be opened from *View › Atlas*.

## Fixed
- Debug build: Atlas.IDE.Base reported `ERangeError` right after loading (mouse buttons back/forward); further range errors on damaged timestamps fixed.
- Atlas windows in the desktop layout have fixed names and are all registered with the IDE. They keep their place after a restart. Rearrange and save an existing layout once.
- Outline, quick toggles, status, notifications and other Atlas popups no longer flicker.
- Delphi 12: the IDE's own Help Insight window no longer appears next to the Atlas tooltip.
- Block lines start at the right line for wrapped `if`, `while`, `for` and `with` heads.
- Windows and menus at the caret open directly below the line at 150 and 200 percent scaling.
- Mutation run: aborts keep everything checked so far; projects with `.rc`, umlauts or an open comment in the .dpr no longer hang or fail.
- Designer: undo of "Create label", "Duplicate" and "Wrap" only deletes what the tool itself created.
- `format-without-settings` without false alarms for own routines of the same name; `duplicate-routine-body` reads each file only once.

## Quality
- The test suite runs under Delphi without leaks and without warm-up tests run ahead. The memory left at shutdown is a criterion of every test run.
