*English version below.*

**Vorabversion.** Atlas 2.0.0-beta.2 behebt einen Fehler der ersten Beta beim Einrichten unter Delphi 12. Alles Weitere zu 2.0 steht in den [Notizen zu 2.0.0-beta.1](https://github.com/xKnockOut/Atlas-IDE-Expert/releases/tag/v2.0.0-beta.1).

## Behoben
- Delphi 12: Der Bau des Plugins aus dem Quelltext (`AtlasUpdate install` bzw. Update) brach in MSBuild mit MSB4066 ab. Die Projektdateien sind korrigiert, die CI prüft sie jetzt mit `Tools/Check-ProjectFiles.ps1`.

---

**Pre-release.** Atlas 2.0.0-beta.2 fixes a problem of the first beta when setting up under Delphi 12. Everything else about 2.0 is in the [notes for 2.0.0-beta.1](https://github.com/xKnockOut/Atlas-IDE-Expert/releases/tag/v2.0.0-beta.1).

## Fixed
- Delphi 12: Building the plugin from source (`AtlasUpdate install` or an update) stopped in MSBuild with MSB4066. The project files are corrected, and CI now checks them with `Tools/Check-ProjectFiles.ps1`.
