# Writing

Back to the [README](../../../README.md)

- **Code completion** in its own popup: detail panel with coloured declaration and docs, filter chips, fuzzy matching, learning order, favourites (Ctrl+D), typo suggestions ("did you mean"), in-editor preview, `+ Unit` hint for units not yet in `uses`
- **Context-aware:** enum values first, set elements with checkboxes, `case` with all or the missing values, only types after `:`, type arguments matching constraints, attributes after `[` without the `Attribute` suffix (DUnitX and JSON first, constructor in the parameter hint, #465), only exception classes after `raise` and `on E:`, inserted as `EFoo.Create('')` with `CreateFmt` alongside, after `on E:` the classes the `try` block can raise first (XMLDoc `<exception cref>`, `StrToInt` → `EConvertError`) and a warning when an earlier handler already catches the class (#483, `completion.exceptionClasses`), members of `with` objects tagged “aus qryOrders”, with a warning when they hide `Self.Name` or a local (#481, `completion.withOrigin`), anonymous method skeletons where a method reference is expected (`TTask.Run(` gives `procedure begin … end`, `TPredicate<TCustomer>` gives `function(const Value: TCustomer): Boolean`, #468, `completion.anonymousMethods`), full `inherited` call, field and parameter names in `FieldByName('`, the form's components, `Sender` with the matching typecast, same names from different units, helper methods, `uses` list with groups
- **Incomplete code:** if a syntax error before the cursor in the current routine or class declaration limits the context, a warning bar on top of the list says “Results may be incomplete · syntax error in line n”; clicking the line jumps there. Without suggestions the empty state names the error. Errors in other routines and the spot being typed do not count (#457, `completion.syntaxNotice`)
- **Unknown names:** create a local variable, inline variable, field or method right from the list; name suggestions from the type
- **Parameter hint** with all overloads, the active parameter and overload choice by argument types; for `Format` and other format routines it names the placeholder of the argument at the cursor ("placeholder 2 of 2 expects integer"), warns about surplus arguments, invalid placeholders and literals of the wrong type, and colours each placeholder and its argument alike in the editor (#451, `completion.formatPlaceholders`; own routines via `formatFunctions` in `.atlas` or `formatMethods` of `format-args`)
- **Templates:** code templates (`tryf`, `forin`, `prop`, …), your own `*.atlas-snippet` files, the IDE's Live Templates, class-aware templates (`prop`, `create`, `free`) and postfix templates (`List.forin`, `Obj.notnil`, `Obj.free`)
- **Slash commands** run after Enter, such as `/uses Unit`, `/extract`, `/inline`, `/fix`, `/explain`, `/case`, `/helper`, `/test`, `/component`, `/unit`, `/sortuses`, `/cleanuses`
- **Generate menu** (Alt+Ins): constructor, properties, overridden methods, interface methods, surround, templates
- **Guard the free:** after `X := TFoo.Create;` an offer for `try … finally X.Free; end;`
- **Editing helpers**: highlight text matching the selection (#709), highlight exit points of a routine with F3 between them (#698), underline reassigned variables with a hover count and an optional "declare as constant" fix (#712), show the type of the selected expression with conversions, chosen overload and constant value, expanding on repeat (#689, Ctrl+Shift+T), keep method bodies in declaration order: new bodies from class completion move to their place in one undo step, "Order implementation like class" with preview (#660), maintain var blocks: convert a variable to an inline variable at its first assignment and back, tidy the var section (remove unused, sort by first use or name, merge equal types), comments move along (#644), toggle block comment (#703, Shift+Alt+A), new line above or below (#700, Shift+Enter, Ctrl+Alt+Enter), surround the selection while typing (#672), remove the surrounding construct (#657, Ctrl+Shift+Del) with preview, Atlas column in the gutter (#768)
- **Conditional compilation**: outline, hover, go to and checks see only the active `{$IFDEF}` branches of the project, the outline shows the branch condition (#845); `{$IF}` understands `SizeOf`, `High`, `Low`, `RTLVersion111` and `Declared`, `{$IFOPT}` follows the switches of the `.dproj` and local `{$R-}`, unknown values keep both branches active, and the hover on a condition explains its value (#847)
- **Variant records**: fields such as `TRect.Left` or `TMessage.WParam` appear in completion, hover, go to and the outline, tagged with their branch (#846)
- **Class helpers with an ancestor**: `class helper (TBaseHelper) for TFoo` is read as a helper, and `Foo.` also offers the members of the ancestor helper (#848)
- **Less common syntax**: several constraints per type parameter, named OLE arguments (`Open(FileName := 'a.docx')`), calling conventions without a semicolon, `cdecl varargs`, `assembler asm`, local routines in anonymous methods, `{$I file.inc}` as a constant value, long `else if` chains, `@@End` labels in `asm` blocks (#861), control characters such as `^C` and the brackets `(.` `.)` (#862, with an inlay hint showing the code) identifiers with `&&` such as Spring4D's `&&op_Equality` (#1137) , empty record constants `= ()` (#1138), `class threadvar`, `class operator In` and `type AnsiString(1252)` (#1140), `end align 16`, attributes in variant record parts, `IBaz<string>=nil` and `%_0101` (#1142), named arguments with a reserved word such as `Foo(Type := 1)`, calling conventions on anonymous methods and attributes on inline variables (`var [Weak] Obj: IFoo := nil`, #1167) as well as method resolution clauses for functions such as `function IFoo.GetX = MyGetX` (#1134) parse without errors; under `{$SCOPEDENUMS ON}` values need their type prefix, members from `{$I}` inside a class belong to the class (#849)
- **Defines from include files**: a `{$DEFINE}` in a file pulled in with `{$I}` counts for greying out, the outline, checks and the linter; an inlay hint behind `{$I}` lists the symbols the file defines (#860)
- **Documentation comments:** `///` creates the XMLDoc skeleton with placeholders
- **Complete statement** (Ctrl+Shift+Enter), **continue patterns** as ghost text, **continue comments** on Enter
- **Formatting** by its own rules (Ctrl+Shift+Alt+L), since RAD Studio 13 no longer has a formatter; regions between `// atlas-format: off` and `// atlas-format: on` stay untouched, and the same formatter runs without the IDE (`--format-check`, `--format-write`, MCP `format_code`, see [Formatting without the IDE](Command-line.md#formatting-without-the-ide))
- **Move and duplicate lines** (Alt+↑/↓, Shift+Alt+↑/↓), **multiple cursors** *(experimental)*, **linked editing of identifiers** *(experimental)*, **paste with uses completion** *(experimental)*
